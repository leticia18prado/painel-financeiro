# painel-financeiro
Painel financeiro interativo desenvolvido com auxílio do Bolt AI, voltado à análise de demonstrações contábeis, indicadores financeiros, análise vertical e horizontal, comparação entre períodos e cálculo do ponto de equilíbrio. Inclui gráficos e diagnóstico financeiro automatizado para apoiar a interpretação dos resultados e a tomada de decisões.

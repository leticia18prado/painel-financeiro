# Painel Financeiro

Painel financeiro interativo desenvolvido com auxílio do Bolt AI, voltado à análise de demonstrações contábeis.

**Acesse o painel:** https://painel-financeiro-contabil.bolt.host

## O que o painel faz

- Cálculo de indicadores financeiros
- Análise vertical e horizontal
- Comparação entre períodos
- Cálculo do ponto de equilíbrio
- Gráficos para visualizar os resultados
- Diagnóstico financeiro automatizado, para apoiar a interpretação dos números e a tomada de decisões

## Método de realização

O projeto foi construído com vibe coding na plataforma Bolt: eu defini as regras contábeis e os indicadores, descrevi o que cada tela deveria mostrar e revisei os resultados e os cálculos gerados.
